7. Generate Personal Access Token to Login in Gitlab

To Comit your changes in VS-Code a Personal Token is required.

The token is required as a prompt for VS code, so it must be saved in a separate text file. 

To generate a token, go to Preferences

Then Access Tokens

Click on Add new token

Put the Expiration date to a year from now and give the token the Scope to read and write repository's

You can then copy the Token and use it in VS-Code after you commit. When the login mask appears.

8. Sync Data to your repository

You can now manually download content and add it to your repository. Go to Moodle, download Exercise 1, unzip it, and copy the extracted files into your local repository folder. You can use File Explorer or VS Code directly whichever you prefer.

New files appear in green in VS Code, indicating that Git is not yet tracking them. Open the Source Control panel, stage your changes (big blue Button), and enter a short commit message summarizing what you added or changed.

(Button to enter Source Control panel)

write a message that summarizes your changes

Click Commit to save your changes locally, then Sync Changes to upload them to the remote repository. If a login prompt appears, enter your OST email address and use your access token as the password.

Go to your gitlab page the files should now be online

9. Create a virtual enviorment

For every project we need different libraries and extensions and sometimes even a very specific python version. For that reason we can creat virtual environments (venv). It's like a dedicated Python installation that is only valid for this project. You have to do this only once, we use the same repository and venv for all exercises.

In VS Code start a new terminal 

Create a new  virtual enviorment

python -m venv .venv

Activate the venv

.venv\Scripts\Activate.ps1

If this fails try: Set-ExecutionPolicy Bypass -Scope Process

Else proceed as usual

You should see that the venv is activated in the bottom left of the terminal

Update pip 

python -m pip install --upgrade pip

Install basic packages

pip install notebook numpy pandas matplotlib

10. For Mac users only

On a Mac, logging into VS Code using a token may not work. Instead, go to your GitLab preferences, navigate to the "Password" section, and reset your password by selecting the "I forgot my password" option.

Once you've set a new password, you can use it to commit changes in VS Code.

11. GIT Ignore

Die Datei .gitignore legt fest, welche Dateien und Ordner Git ignorieren soll, damit sie nicht versehentlich ins Repository aufgenommen werden.
